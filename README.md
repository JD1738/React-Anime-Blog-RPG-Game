# React Anime Blog RPG Game

An anime website blog and a short game on the ACE engine, integrated and made in React.

## Available Scripts

In the project directory, you can run:

- `npm start` - Runs the app in the development mode.
- `npm test` - Launches the test runner in the interactive watch mode.
- `npm run build` - Builds the app for production.
- `npm run eject` - Ejects the project configuration (be careful with this).

## Features

- Anime blog
- Interactive RPG game
- Built with React
